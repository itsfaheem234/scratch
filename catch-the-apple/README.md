# apple-catcher
a simple and fun scratch game where the player controls a basket to catch falling apples and score points!

## about the game
apple-catcher is a 2D arcade-style game developed using scratch.

the objective is simple: move the basket from side to side and catch as many falling apples as possible. the game gets progressively more challenging as the player tries to achieve a high score.

## how to play

1. start the game.
2. use the left and right arrow keys to move the basket.
3. catch the falling apples to increase your score.
4. avoid missing apples.
5. try to achieve the highest score possible!

## features

1. falling apple mechanics
2. player-controlled basket
3. score tracking
4. randomized apple positions
5. keyboard controls
6. simple arcade-style gameplay
